# ClinicalOS — Clinical AI Governance & Decision Support Platform

> Executive MBA Capstone Project

## Overview

ClinicalOS is a healthcare AI governance and clinical decision support platform with three user surfaces:

- **Clinician Panel** — Embedded in EHR workflows for pharmacy alerts and nursing handoffs
- **Leadership Dashboard** — Outcomes, metrics, and AI briefings for clinical operations leaders
- **Governance Control Plane** — Use case registry, RBAC, audit logs, and allowlists

## Quick Start

```bash
cd frontend
npm install
npm run dev
# Opens at http://localhost:5173
```

No backend required. All data is client-side mocks.

## Tech Stack

- React 18 + TypeScript
- Material UI + Tailwind CSS
- Vite
- React Router

## Project Structure

- `frontend/` — React application
- `backend/` — API server (not required for demo)
